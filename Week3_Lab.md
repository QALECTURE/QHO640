# QHO640 Contemporary Web Applications — Week 3 Seminar Lab

## RideLab: Build an Uber-inspired driver discovery app with React

**Duration:** 2 hours | **Level:** Beginner to intermediate | **Tools:** VS Code, Node.js, npm, browser, Git

> **Teaching simulation:** RideLab uses original UI, fictional drivers, fictional map coordinates and simulated arrival times. It is **not affiliated with Uber** and does not use live GPS, map tiles, driver data or a booking API.

### The real-world problem

You request a ride. The app has a collection of drivers. It must check which drivers are available, show only suitable vehicle types, rank drivers by arrival time and display driver cards. **How can JavaScript arrays and React do this?**

### Learning outcomes

By the end of this seminar, you should be able to:

1. Represent driver records as **objects inside an array** and iterate using `for`, `for...of` and `forEach()`.
2. Use `filter()`, `map()`, `find()`, `some()`, `every()`, `reduce()`, `slice()`, `sort()`, `includes()`, `indexOf()` and `Array.from()` to solve problems.
3. Explain `concat()`, spread syntax, shallow cloning, `flat()` and insertion/removal methods.
4. Render React lists with JSX and **stable `key` values**, and connect components, props, state and event handlers.
5. Build and test a working simulated ride-discovery interface, then complete independent changes.

### Step 7. Animated map: map() and keys

**File:** `src/components/DriverMap.jsx`

```jsx
export default function DriverMap({ drivers, visibleIds, selectedId }) {
  return (
    <section className="map" aria-label="Illustrated fictional city map with animated driver markers">
      <div className="map-road horizontal one"/><div className="map-road horizontal two"/>
      <div className="map-road vertical one"/><div className="map-road vertical two"/>
      <div className="park">CITY PARK</div><div className="river">RIVER</div>
      <div className="map-label top">NORTH QUARTER</div><div className="map-label bottom">CENTRAL DISTRICT</div>
      <div className="pickup"><span>●</span><strong>Your pickup</strong></div>
      {drivers.map(driver => {
        const visible = visibleIds.includes(driver.id);
        return (
          <div key={driver.id}
            className={`car-marker ${selectedId === driver.id ? 'chosen' : ''} ${!visible ? 'faded' : ''}`}
            style={{ left: `${driver.x}%`, top: `${driver.y}%`, '--car': driver.colour }}
            title={`${driver.name}: ${driver.eta} minutes`}>
            <span aria-hidden="true">◆</span><small>{driver.eta}m</small>
          </div>
        );
      })}
      <p className="map-disclaimer">Animated illustration · fictional data · not live GPS</p>
    </section>
  );
}
```

**Understand it:** `drivers.map(...)` renders one marker for each driver. `visibleIds.includes(driver.id)` determines which markers fade. `key={driver.id}` lets React track marker identity when the list changes. CSS animates markers; it is **not real-time driver movement**.

### Step 8. Main application: array methods, state and events

**File:** `src/App.jsx`

```jsx
import { useState } from 'react';
import { initialDrivers } from './data/drivers.js';
import DriverCard from './components/DriverCard.jsx';
import DriverMap from './components/DriverMap.jsx';

export default function App() {
  const [drivers, setDrivers] = useState(initialDrivers);
  const [rideType, setRideType] = useState('All');
  const [maxEta, setMaxEta] = useState(8);
  const [sortBy, setSortBy] = useState('eta');
  const [selectedId, setSelectedId] = useState(null);

  // filter(): keep only drivers matching ALL selected conditions.
  const matchingDrivers = drivers.filter(driver =>
    driver.available &&
    driver.eta <= maxEta &&
    (rideType === 'All' || driver.type === rideType)
  );

  // sort() changes its array, so first copy with spread syntax.
  const sortedDrivers = [...matchingDrivers].sort((a, b) =>
    sortBy === 'rating' ? b.rating - a.rating : a.eta - b.eta
  );

  // some(), reduce(), find() and slice() each answer a different question.
  const anyMatch = matchingDrivers.some(driver => driver.eta <= 3);
  const averageEta = matchingDrivers.length
    ? matchingDrivers.reduce((total, driver) => total + driver.eta, 0) / matchingDrivers.length
    : null;
  const selectedDriver = drivers.find(driver => driver.id === selectedId);
  const fastestThree = [...matchingDrivers].sort((a, b) => a.eta - b.eta).slice(0, 3);
  const visibleIds = sortedDrivers.map(driver => driver.id);

  function selectDriver(id) { setSelectedId(id); }
  function addDemoDriver() {
    if (drivers.some(driver => driver.id === 107)) return;
    setDrivers(current => [...current, {
      id: 107, name: 'Grace', car: 'Hyundai Ioniq', type: 'Standard',
      eta: 4, rating: 4.8, available: true, x: 66, y: 47, colour: '#334155'
    }]);
  }
  function removeDemoDriver() {
    setDrivers(current => current.filter(driver => driver.id !== 107));
    if (selectedId === 107) setSelectedId(null);
  }
  function reset() {
    setDrivers(initialDrivers); setRideType('All'); setMaxEta(8);
    setSortBy('eta'); setSelectedId(null);
  }

  return (
    <div className="app-shell">
      <header className="site-header">
        <div className="brand">ride<span>lab</span><small>QHO640 · Week 3</small></div>
        <div className="header-right"><span className="live-dot"/> SIMULATION MODE</div>
      </header>
      <main className="layout">
        <section className="left-panel">
          <div className="intro"><span className="eyebrow">A familiar ride-hailing experience</span>
            <h1>Find your ride</h1><p>Explore how JavaScript arrays power driver discovery and React list rendering.</p>
          </div>
          <div className="route-card">
            <div><span className="route-pin pickup-pin"/><span>Pickup</span><strong>University Campus</strong></div>
            <div><span className="route-pin destination-pin"/><span>Destination</span><strong>City Station</strong></div>
          </div>
          <div className="controls">
            <label>Ride type<select value={rideType} onChange={e => { setRideType(e.target.value); setSelectedId(null); }}>
              <option>All</option><option>Standard</option><option>Comfort</option><option>XL</option>
            </select></label>
            <label>Maximum arrival: <strong>{maxEta} min</strong>
              <input type="range" min="2" max="10" value={maxEta} onChange={e => { setMaxEta(Number(e.target.value)); setSelectedId(null); }}/>
            </label>
            <label>Sort drivers<select value={sortBy} onChange={e => setSortBy(e.target.value)}>
              <option value="eta">Fastest arrival</option><option value="rating">Highest rating</option>
            </select></label>
          </div>
          <div className="list-heading"><h2>Available drivers <span>({sortedDrivers.length})</span></h2></div>
          <div className="driver-list">
            {sortedDrivers.length === 0
              ? <p className="empty">No matching drivers. Try a different ride type or arrival time.</p>
              : sortedDrivers.map(driver => (
                  <DriverCard key={driver.id} driver={driver}
                    selected={selectedId === driver.id} onSelect={selectDriver}/>
                ))}
          </div>
          <div className="actions">
            <button onClick={() => { const first = sortedDrivers[0]; setSelectedId(first ? first.id : null); }}>
              Find fastest matching driver
            </button>
            <button className="secondary" onClick={reset}>Reset</button>
          </div>
          {selectedDriver && <p className="confirmation" role="status">Driver selected: <strong>{selectedDriver.name}</strong> · {selectedDriver.eta} min estimated arrival. No real booking was made.</p>}
        </section>
        <section className="right-panel">
          <DriverMap drivers={drivers} visibleIds={visibleIds} selectedId={selectedId}/>
          <div className="metrics">
            <div><small>Matching drivers</small><strong>{matchingDrivers.length}</strong><code>filter()</code></div>
            <div><small>Average ETA</small><strong>{averageEta === null ? '—' : `${averageEta.toFixed(1)}m`}</strong><code>reduce()</code></div>
            <div><small>Any within 3 min?</small><strong>{anyMatch ? 'Yes' : 'No'}</strong><code>some()</code></div>
          </div>
          <div className="learning-card">
            <h2>What just happened in JavaScript?</h2>
            <p><code>filter()</code> chooses matching drivers; <code>sort()</code> orders them; <code>map()</code> creates React cards; <code>find()</code> identifies a selected driver.</p>
            <p><strong>Top three fastest:</strong> {fastestThree.map(d => d.name).join(', ') || 'None'} <code>slice(0, 3)</code></p>
            <div className="actions small-actions"><button onClick={addDemoDriver}>Add Grace (spread)</button><button className="secondary" onClick={removeDemoDriver}>Remove Grace (filter)</button></div>
          </div>
        </section>
      </main>
      <footer>Original educational ride-hailing simulation. Not affiliated with Uber. Fictional locations, drivers and ETAs.</footer>
    </div>
  );
}
```

**Understand it:** This is the main Week 3 exercise. `useState` holds the full driver list, ride type, arrival-time threshold, sort order and selection. `filter()` chooses drivers; copying before `sort()` avoids mutating the source; `map()` renders driver cards; `find()` retrieves the chosen driver; `reduce()` calculates the average; `some()` checks a condition; `slice()` shows the fastest three. New driver insertion uses spread; removal uses `filter()`.

### Explain the JavaScript pipeline

```text
Array of driver objects
        |
        v
filter(available + ride type + max ETA)
        |
        v
[...matchingDrivers].sort(by ETA or rating)
        |
        v
map(driver => <DriverCard key={driver.id} ... />)
        |
        v
React updates the visible driver cards
```

**Discuss:** Why does `map()` create JSX cards, while `forEach()` would not directly produce the array of JSX elements we want? Why do we copy before sorting? Why do cards need stable keys?

```javascript
const sample = [
  { id: 1, name: 'Aisha', eta: 3, available: true, type: 'Standard' },
  { id: 2, name: 'Ben', eta: 7, available: true, type: 'Standard' },
  { id: 3, name: 'Chloe', eta: 4, available: true, type: 'Comfort' },
  { id: 4, name: 'Daniel', eta: 8, available: false, type: 'XL' }
];
```

| Task | Try this | Expected result |
|---|---|---|
| Iterate names | `for (const d of sample) console.log(d.name)` | Four names |
| Index-based loop | `for (let i=0; i<sample.length; i++) console.log(i, sample[i].name)` | Index 0–3 |
| `forEach()` | `sample.forEach((d,i) => console.log(i,d.name))` | Index and name |
| `map()` | `sample.map(d => d.name)` | Array of four names |
| `Array.from()` | `Array.from('RIDE')` | `['R','I','D','E']` |
| `filter()` | `sample.filter(d => d.available)` | Three drivers |
| `find()` | `sample.find(d => d.eta <= 3)` | Aisha object |
| `some()` | `sample.some(d => d.eta <= 3)` | `true` |
| `every()` | `sample.every(d => d.available)` | `false` |
| `reduce()` | `sample.reduce((sum,d) => sum + d.eta, 0)` | `22` |
| `slice()` | `sample.slice(0,2)` | First two objects |
| `sort()` safely | `[...sample].sort((a,b) => a.eta-b.eta)` | Aisha, Chloe, Ben, Daniel |
| `includes()` | `['Standard','XL'].includes('XL')` | `true` |
| `indexOf()` | `['Standard','XL'].indexOf('XL')` | `1` |
| `concat()` | `['Aisha'].concat(['Ben'])` | Two names |
| Spread combine | `[...['Aisha'], ...['Ben']]` | Two names |
| Shallow clone | `const copy = [...sample]; copy === sample` | `false` |
| `flat()` | `[['Aisha'],['Ben','Chloe']].flat()` | Three names |
| `push()` | `const a=[1]; a.push(2); a` | `[1,2]`, mutated |
| `unshift()` | `const a=[2]; a.unshift(1); a` | `[1,2]`, mutated |
| `pop()` | `const a=[1,2]; a.pop(); a` | `[1]`, mutated |
| `shift()` | `const a=[1,2]; a.shift(); a` | `[2]`, mutated |
| `splice()` | `const a=[1,2,3]; a.splice(1,1); a` | `[1,3]`, mutated |

**Key distinction:** `filter()`, `map()`, `slice()`, `concat()` and spread create new arrays; `sort()`, `push()`, `pop()`, `shift()`, `unshift()` and `splice()` mutate the array they operate on. `Array.from()` also creates a new array. For React state, prefer non-mutating updates.

<details><summary>1. What is an array?</summary>A collection of values accessed by indexes beginning at zero.</details>
