### Step 7: ProductCard — reusable components and props

**File:** `src/components/ProductCard.jsx`

```jsx
export default function ProductCard({ product, onAdd, quantityInCart }) {
  const soldOut = product.stock === 0;

  return (
    <article className="product-card">
      <div className="product-art" aria-hidden="true">{product.icon}</div>
      <span className="category-tag">{product.category}</span>
      <h3>{product.name}</h3>
      <p className="muted">In stock: {product.stock}</p>
      <div className="product-bottom">
        <strong>£{product.price.toFixed(2)}</strong>
        <button disabled={soldOut} onClick={() => onAdd(product)}>
          {soldOut ? 'Out of stock' : 'Add to basket'}
        </button>
      </div>
      {quantityInCart > 0 && (
        <p className="in-basket">In basket: {quantityInCart}</p>
      )}
    </article>
  );
}
```

**Understand it:** The component receives three **props**: `product`, `onAdd`, and `quantityInCart`. JSX `{...}` inserts JavaScript values. The `onClick` handler calls the function passed by the parent. `{quantityInCart > 0 && (...)}` is **conditional rendering**. The initial disabled state only checks `stock === 0`; you will improve the stock rule in Challenge 2.

### Step 8: Products page — state, events, map and filter

**File:** `src/pages/Products.jsx`

```jsx
import { useState } from 'react';
import { products } from '../data/products.js';
import ProductCard from '../components/ProductCard.jsx';

export default function Products({ onAdd, cart }) {
  const [search, setSearch] = useState('');
  const [category, setCategory] = useState('All');

  const visibleProducts = products.filter((product) => {
    const matchesSearch = product.name.toLowerCase().includes(search.toLowerCase());
    const matchesCategory = category === 'All' || product.category === category;
    return matchesSearch && matchesCategory;
  });

  return (
    <section>
      <div className="section-heading">
        <div><p className="eyebrow">Browse</p><h1>Our products</h1></div>
        <p className="muted">{visibleProducts.length} product(s) shown</p>
      </div>
      <div className="filters">
        <label>
          Search products
          <input value={search} onChange={(event) => setSearch(event.target.value)} placeholder="Try keyboard" />
        </label>
        <label>
          Category
          <select value={category} onChange={(event) => setCategory(event.target.value)}>
            <option>All</option><option>Audio</option><option>Computing</option><option>Home</option>
          </select>
        </label>
      </div>
      {visibleProducts.length === 0 ? (
        <p className="empty">No products found. Try a different search.</p>
      ) : (
        <div className="product-grid">
          {visibleProducts.map((product) => (
            <ProductCard
              key={product.id}
              product={product}
              onAdd={onAdd}
              quantityInCart={cart.find((item) => item.id === product.id)?.quantity ?? 0}
            />
          ))}
        </div>
      )}
    </section>
  );
}
```

**Understand it:** `useState` remembers the current search text and category. `onChange` updates state as students type. `filter()` selects matching products, and `map()` converts each product into a `ProductCard`. Each card needs a stable `key` (we use `product.id`). The `?.` and `??` operators safely handle items that are not yet in the basket.

### Step 9: Basket page — list rendering and totals

**File:** `src/pages/Basket.jsx`

```jsx
import { Link } from 'react-router-dom';

export default function Basket({ cart, onRemove, onChangeQuantity }) {
  const total = cart.reduce((sum, item) => sum + item.price * item.quantity, 0);

  return (
    <section>
      <p className="eyebrow">Your order</p>
      <h1>Shopping basket</h1>
      {cart.length === 0 ? (
        <div className="empty">
          <p>Your basket is empty.</p>
          <Link to="/products">Browse products</Link>
        </div>
      ) : (
        <>
          <div className="basket-list">
            {cart.map((item) => (
              <div className="basket-item" key={item.id}>
                <div className="mini-art" aria-hidden="true">{item.icon}</div>
                <div className="basket-info">
                  <strong>{item.name}</strong>
                  <span className="muted">£{item.price.toFixed(2)} each</span>
                </div>
                <div className="quantity-controls">
                  <button aria-label={`Remove one ${item.name}`} onClick={() => onChangeQuantity(item.id, -1)}>−</button>
                  <span>{item.quantity}</span>
                  <button aria-label={`Add one ${item.name}`} onClick={() => onChangeQuantity(item.id, 1)}>+</button>
                </div>
                <button className="remove-button" onClick={() => onRemove(item.id)}>Remove</button>
              </div>
            ))}
          </div>
          <div className="basket-total"><span>Subtotal</span><strong>£{total.toFixed(2)}</strong></div>
          <p className="muted">Demonstration only. No real payment is taken.</p>
        </>
      )}
    </section>
  );
}
```

**Understand it:** `cart.map(...)` renders a row for each basket item. `reduce()` calculates the subtotal. The `+` and `−` buttons call the parent-provided `onChangeQuantity` function. When `cart.length === 0`, the component shows an empty-basket message instead of the item list.

### Step 10: App — shared state, routing and immutable updates

**File:** `src/App.jsx`

```jsx
import { useState } from 'react';
import { NavLink, Route, Routes } from 'react-router-dom';
import Home from './pages/Home.jsx';
import Products from './pages/Products.jsx';
import Basket from './pages/Basket.jsx';

export default function App() {
  const [cart, setCart] = useState([]);

  function addToCart(product) {
    setCart((current) => {
      const existing = current.find((item) => item.id === product.id);
      if (existing) {
        return current.map((item) => item.id === product.id
          ? { ...item, quantity: item.quantity + 1 }
          : item);
      }
      return [...current, { ...product, quantity: 1 }];
    });
  }

  function removeFromCart(id) {
    setCart((current) => current.filter((item) => item.id !== id));
  }

  function changeQuantity(id, difference) {
    setCart((current) => current
      .map((item) => item.id === id
        ? { ...item, quantity: item.quantity + difference }
        : item)
      .filter((item) => item.quantity > 0));
  }

  const basketCount = cart.reduce((sum, item) => sum + item.quantity, 0);

  return (
    <>
      <header className="site-header">
        <NavLink className="brand" to="/">shop<span>lab</span></NavLink>
        <nav aria-label="Main navigation">
          <NavLink to="/" end>Home</NavLink>
          <NavLink to="/products">Products</NavLink>
          <NavLink to="/basket">Basket <span className="basket-badge">{basketCount}</span></NavLink>
        </nav>
      </header>
      <main className="container">
        <Routes>
          <Route path="/" element={<Home />} />
          <Route path="/products" element={<Products onAdd={addToCart} cart={cart} />} />
          <Route path="/basket" element={<Basket cart={cart} onRemove={removeFromCart} onChangeQuantity={changeQuantity} />} />
          <Route path="*" element={<div className="empty"><h2>Page not found</h2><NavLink to="/">Return home</NavLink></div>} />
        </Routes>
      </main>
      <footer className="site-footer">ShopLab is an original teaching simulation, not an Amazon service.</footer>
    </>
  );
}
```

**Understand it:** The **basket state lives in `App`**, because both Products and Basket need access to it. `addToCart` uses `find()` to detect existing items, `map()` to update quantity and the spread operator `...` to create new arrays/objects. `removeFromCart` uses `filter()`. `<Routes>` chooses which page to render for each URL. **Important:** State is not saved after a refresh in this base version.

## Part 4 — Knowledge check (optional, if you finish early)

<details><summary>1. What is the difference between props and state?</summary>Props are inputs passed to a component; state is data a component manages and can update.</details>

<details><summary>2. Why do we use `key={product.id}` when rendering cards?</summary>React uses stable keys to track the identity of items in a list across updates.</details>

<details><summary>3. What does `filter()` do in the Products page?</summary>Returns a new array containing only products matching search and category conditions.</details>

<details><summary>4. What does `map()` do?</summary>Transforms each array item into a React element or another value.</details>

<details><summary>5. What does `useState` do?</summary>Stores component state and provides a setter that triggers a React update.</details>

<details><summary>6. What is JSX?</summary>A JavaScript syntax extension for describing UI elements.</details>

<details><summary>7. Why is the basket state in App rather than ProductCard?</summary>Products and Basket both need shared access to the basket, so state is lifted to their common parent.</details>

<details><summary>8. What does BrowserRouter do?</summary>Provides routing context for client-side navigation based on URLs.</details>

<details><summary>9. Why does a page refresh reset the basket?</summary>The base app stores the basket only in React memory; persistence would require storage or a backend.</details>

<details><summary>10. Why avoid mutating arrays directly in React state?</summary>New arrays/objects make state changes predictable and help React detect updates.</details>
